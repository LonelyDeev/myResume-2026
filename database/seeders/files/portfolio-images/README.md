## نحوه استفاده

1. وارد پنل مدیریت شوید: `/admin`
2. منوی **نمونه‌کارها** → روی پروژه مربوطه **ویرایش** کنید
3. در بخش **«تصویر اصلی پروژه»** فایل PNG مربوطه را آپلود کنید
4. ذخیره — تصویر به‌صورت خودکار کاور کارت و اسلاید اول گالری مودال می‌شود

> نکته: همین تصاویر را می‌توانید به‌عنوان اولین تصویر «گالری تصاویر پروژه» هم آپلود کنید تا در مودال گالری کامل نمایش داده شوند.
